# Mission Control UI kit
Phone-first click-through composed from the Spacetraders components. Glance → tap a Ship → Why; tabs for Ships and Records. A small sim advances HARDBARGAIN-1 and the probe; sales land with the SOLD toast and count-up.
The full prototype (all five situations, 120-Ship fleet, desktop, Grafana mocks) is `/Mission Control.dc.html`.
