REFERENCE · SpaceTraders + Elixir

Glossary

The canonical language of this course. Every lesson uses these terms. If a term isn't here, it hasn't been taught yet.

The game

SpaceTraders
A headless space-trading game: every action — navigate, mine, trade, buy a Ship — is an HTTP endpoint. All game state lives on the game's servers; your code is only a remote control. Avoid: "the API game" as a term of art; just call it the game.
Agent
The in-game player identity. Owns its credits, its fleet, its contracts, and its headquarters. Avoid: player, user
System
A named region of space containing waypoints, e.g. X1-UX81.
Waypoint
A specific location in a System, e.g. X1-UX81-A1; the atomic unit of movement. Avoid: planet, station
Ship
A vessel an Agent owns. Travels between waypoints, carries cargo, consumes fuel, and is subject to cooldowns.
Contract
An in-game mission (PROCUREMENT, TRANSPORT, SHUTTLE) with a deadline and payment terms.
Headless
Having no built-in UI — you interact with the game only through its API.

The stack

Elixir
A functional programming language running on the Erlang VM (the BEAM). Functions over values; no classes.
Phoenix
Elixir's web framework. This repo is a Phoenix app (Bandit + LiveView).
Module
A named collection of functions, usually one per file: defmodule SpaceTraders.API do … end.
Function
A named unit of code that returns the value of its last expression: def get_status do … end.
Tuple
An ordered group of values, e.g. {:ok, value}.
Pattern match
Assigning (and asserting) by shape: {:ok, data} = result succeeds only when result is a two-element tuple whose first element is :ok.
{:ok, _} / {:error, _}
Elixir's convention for "it worked / it didn't". Every function in SpaceTraders.API returns one of these.
Pipe (|>)
Threads the value on the left into the function on the right as its first argument: x |> f() is f(x).
Mix
Elixir's project tool: compiles, runs (mix run), tests (mix test).
Req
The HTTP client library this app uses to talk to the game.
Decode
Turning the game's JSON reply into Elixir values (maps and structs).

Terms follow CONTEXT.md for the game and the repo. See docs.spacetraders.io for game rules and elixir-lang.org for the language.
