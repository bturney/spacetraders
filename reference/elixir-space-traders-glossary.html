Elixir and SpaceTraders glossary

Small vocabulary for reading the first lessons.

Elixir

Atom
A named constant such as :ok or :ship_in_transit. Similar to a safe enum value.
Tuple
A fixed-size ordered value, such as {:ok, ship}. It commonly makes success and error paths explicit.
Pattern match
Shape-based binding or dispatch. {:ok, value} = result both verifies the shape and binds value.
Function clause
One implementation selected by argument shape or a guard. This replaces many conditional branches and method overloads.
Process
An isolated BEAM runtime unit with its own mailbox and state. It is not an operating-system process or a Java thread.
Supervisor
A process that starts and restarts child processes according to a declared strategy.

SpaceTraders

Operator
The human who drives the dashboard and authorizes external actions.
Agent
The in-game identity that owns credits, Fleet, contracts, and headquarters.
Ship
A vessel owned by exactly one Agent. Each running ShipServer owns one Ship's in-memory timers.
Job
A durable Operator-selected outcome for one Ship, driven by a Policy.
Intent
A state-aware request for a Ship outcome, such as reaching a Waypoint. It is not a fixed API-call script.
Manual Control
The Operator as an alternate caller of one-off Intents or direct game actions. It is not a durable Ship mode.
