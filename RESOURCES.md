# Elixir and SpaceTraders Resources

## Knowledge

- [Elixir 1.18 Introduction](https://hexdocs.pm/elixir/1.18.4/introduction.html)
  Official language introduction. Use for: values, pattern matching, modules, and control flow.
- [Elixir 1.18 Patterns and Guards](https://hexdocs.pm/elixir/1.18.4/patterns-and-guards.html)
  Official reference for the core Elixir dispatch mechanism. Use for: understanding function clauses in contexts and tests.
- [Elixir Introduction to Mix](https://hexdocs.pm/elixir/1.18.4/introduction-to-mix.html)
  Official guide to Mix projects and tasks. Use for: the pinned toolchain, running focused tests, and project commands.
- [Elixir GenServer](https://hexdocs.pm/elixir/1.18.4/GenServer.html)
  Official behavior reference. Use for: ShipServer calls, casts, state, and timer messages.
- [Elixir Supervisor](https://hexdocs.pm/elixir/1.18.4/Supervisor.html)
  Official behavior reference. Use for: application startup and dynamic ShipServer ownership.
- [Phoenix 1.8 Overview](https://hexdocs.pm/phoenix/1.8.0/overview.html)
  Official framework guide. Use for: routers, controllers, contexts, and endpoint structure.
- [Phoenix LiveView](https://hexdocs.pm/phoenix_live_view/Phoenix.LiveView.html)
  Official LiveView API and lifecycle reference. Use for: `mount/3`, `handle_event/3`, and `handle_info/2`.
- [Project Context](CONTEXT.md)
  The application glossary. Use its terms, especially Agent, Operator, Ship, Job, Intent, and Manual Control.

## Wisdom

- [Elixir Forum](https://elixirforum.com/)
  Moderated practitioner community. Use for: design questions after first reproducing the issue with a small example.
- [Elixir Slack](https://elixir-slackin.herokuapp.com/)
  Practitioner chat community. Use for: short questions about tooling and ecosystem conventions.
