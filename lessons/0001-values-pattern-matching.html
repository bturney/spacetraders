Lesson 1 / 30 minutes / Elixir core

Values and pattern matching

Start with four small pieces: a named value, a pair of values, a variable, and a choice based on that pair.

1. A value is some data

A value is a piece of data a program can use. You already know values such as the number 42 and the text "hello".

Elixir also has atoms. An atom is a fixed named value that starts with a colon:

:ok
:error
:cooldown_active

Read them aloud as “ok”, “error”, and “cooldown active”. They are not variables and do not change. This application uses atoms for small, known states, like a Ship being ready or on Cooldown.

2. A tuple keeps values together

Curly braces make a tuple: one value that contains a fixed number of values in order.

{:error, :cooldown_active}

Think of this as a two-slot card:

first slot:   :error
second slot:  :cooldown_active

In this project, the first slot often says whether an operation worked. The second slot gives useful detail. A successful operation might return {:ok, ship}; an unsuccessful one can return {:error, :cooldown_active}.

Try it slowly in IEx

IEx is Elixir's interactive prompt. Run these one line at a time. After each line, read what IEx prints before entering the next one.

source scripts/_toolchain.sh
iex

First, enter an atom:

:ok

IEx prints :ok. Next, enter a tuple:

{:error, :cooldown_active}

IEx prints the same tuple. You have asked it to evaluate data, not to call the SpaceTraders application.

3. Give the tuple a temporary name

A variable is a name you use to refer to a value. This line puts the tuple behind the name result:

result = {:error, :cooldown_active}

In Elixir, = is called the match operator. At this beginner stage, read that line as “put this value in result”. Later lessons explain its stricter matching behavior.

Enter the line above in IEx, then enter:

result

IEx prints {:error, :cooldown_active} because result refers to that tuple.

4. Choose what to do with case

case examines one value. It runs the line whose left side has the same shape as that value. The arrow -> means “then produce this result”.

case result do
  :ok -> "the Ship is ready"
  {:error, reason} -> reason
end

Enter that whole block in IEx. It prints :cooldown_active.

Why? result is not :ok, so Elixir skips the first line. It does match {:error, reason}. The name reason becomes the second item in the tuple, so this branch returns :cooldown_active.

Do not worry about writing this from memory yet. Your goal is only to recognize the two shapes:

:ok
{:error, reason}

Which value is an Elixir atom?

An atom starts with a colon. Quotation marks create text, and curly braces create a tuple containing more than one value.
