SpaceTraders / server-first Elixir course

Learn Elixir through SpaceTraders

A self-directed course for an experienced engineer who knows the game domain but is new to Elixir and OTP.

Environment

Use the Linux server as the development machine. Source scripts/_toolchain.sh before every Elixir command. Use Kimaki tunnels for browser access and tuistory for persistent commands. A MacBook Elixir install is not required.

Open these lessons from the server

Start the static course server through the tunnel. It copies only lessons/, reference/, and the teaching assets into a temporary directory; it never exposes the repository root.

kimaki tunnel -- scripts/serve-lessons

For a persistent session, run that command through a named tuistory session. Open the tunnel URL it prints, then choose a lesson from this page.

First sequence

  1. Values and pattern matching - read the success and error vocabulary used throughout the app.
  2. A health request through Phoenix - follow GET /health from route to controller to test.
  3. The LiveView event loop - trace an Operator command through one persistent server process.
  4. One Ship, one process - understand the supervision tree and the ShipServer.

Study independently

Do each lesson in order. Predict before revealing an answer or running a command. The quizzes give immediate feedback; the repository tests give executable feedback.
