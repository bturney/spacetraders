# SQLite (ecto_sqlite3) for local state, Postgres deferred

**Status:** retired. PostgreSQL is now the application store; this record is
preserved as historical context only.

Superseded for the autonomous runtime by
[ADR 0010](0010-autonomous-runtime.md). The SQLite implementation and cutover
path have been removed.

This was the original Phase-1 decision. It is no longer an implementation
constraint.
